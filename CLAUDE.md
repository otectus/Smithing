# Ote's Smithing - Forge 1.20.1 Mod

## Orientation
Registration inventory and package layout live in `MODMAP.md` (generated by
`.mcmod-tools/modmap.py`). Read that instead of crawling `src/`. The design brief is
`docs/Otes_Smithing_Forge_1.20.1_Implementation_Plan.md`; datapack and Java API formats are in `docs/API.md`.

## Quick Reference
- **Mod ID**: `otes_smithing`
- **Package**: `com.otectus.otessmithing`
- **MC / Loader / Java / JEI**: see `gradle.properties`
- **Mappings**: official
- **Network protocol version**: `ModNetwork.VERSION`

Version numbers live only in `gradle.properties`; `processResources` expands them into `mods.toml`.

## Build
- `./gradlew compileJava` - compile only
- `./gradlew build` - reobfuscated jar in `build/libs/`
- `./gradlew runGameTestServer` - headless GameTests (`src/gameTest`, template `otes_smithing:empty`); exits non-zero on failure
- `./gradlew runGameTestServer -PcompatMods` - same, with Spartan Weaponry, Spartan Shields and Immersive Armors (Modrinth ids in `gradle.properties`); writes `run-gametest/logs/otes_smithing_report.txt`
- `./gradlew runClient -PsmokeTest` - loads the pack-test agent (`src/packTest`): creates a fresh flat world, checks smithing data, stages every station and screen, saves `run/screenshots/packtest_*.png`, writes `run/packtest/packtest-result.json`, quits
- **Release gate (every release):** `./gradlew build packTestJar`, then `python3 tools/packtest/ultima_pack_test.py --expect spartan,shields,upgrades`. Runs the jar in an isolated copy of the Ultima CurseForge instance under `build/packtest/<label>/` (the real instance is never modified) and opens a game window on the desktop. Exit 0 = pass; evidence in that folder's `summary.json`, `client.log`, `captures/` and `screenshots/`
- `python3 tools/generate_spartan_compat.py` - regenerates `recipes/compat/spartanweaponry/` from the Spartan Weaponry jar
- `python3 tools/generate_textures.py` - regenerates all item/block/particle/GUI textures

## Structure
```
api/        public Java API (OtesSmithingAPI + interfaces, IMC method names)
material/   families, units, datapack loaders, resolver; no gameplay state
recipe/     SmithingRecipe + serializer, auto-detection, SmithingData (server snapshot rebuilt on reload)
minigame/   deterministic rules shared by client and server, patterns, SessionManager (server only)
quality/    QualityData NBT, multipliers, attribute/mining/durability hooks
workpiece/  hot workpiece data and its NBT codec
block/ blockentity/ item/ registry/ network/ config/ command/ event/ util/ advancement/ guide/
compat/villager/  trades; compat/spartanweaponry/ Spartan types (only after a ModList check)
client/     everything client-only: screens, renderers, particle, tooltip, packet handlers, JEI plugin (client/compat/jei)
mixin/      ItemStackMixin (durability conversion at the head of ItemStack#hurt); client/HumanoidModelMixin (tongs stab)
```

## Key Dependencies
- JEI - optional; `compileOnly` API, `runtimeOnly` in dev. The plugin lives under `client/` and is only loaded by JEI.
- Spartan Weaponry - optional; `compileOnly`. Its recipes are data (`forge:mod_loaded` first); Java access only through `compat/spartanweaponry/SpartanCompat`.

## Conventions
- `DeferredRegister` per registry in `registry/`; registration on the mod bus, gameplay on the Forge bus via `@Mod.EventBusSubscriber`.
- Client code is reached only through `DistExecutor` (packets, `SmithingGuideItem`, `OtesSmithing` constructor).
- Config: `ServerConfig` (SERVER, synced) and `ClientConfig` (CLIENT, presentation only). Read values through their `get(...)` helpers, which fall back to defaults when no world is loaded.
- Server is authoritative: clients send input events only; `SessionManager` validates timing (`SessionTiming`) and scores. Never add a packet that carries a score or an item.
- Auxiliary ingredients move only between the player inventory and the forge's persisted escrow; escrow is refunded exactly once (see `SessionManager` class comment).
- Smithing data is resolved after tags bind: `ServerStartedEvent` and `OnDatapackSyncEvent` call `SmithingData.rebuild`, which rewrites the recipe manager (adds automatic recipes, removes suppressed ones).
- Player-facing text is always a translation key in `assets/otes_smithing/lang/en_us.json`, guide text included.
- Mixin config `otes_smithing.mixins.json`; plain Mixin injectors only.

## Terminology
- "units" = material units (nugget 1, ingot 9, block 81). "Forge score" = durability quality, "Anvil score" = efficacy quality.
- A "workpiece" is the hot unfinished item; states `FORGED` (after the forge) and `SHAPED` (after the anvil).
